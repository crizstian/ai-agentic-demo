SQLi, XSS, CMDi matched by CRS/ModSecurity rules inside TME sidecar. Deterministic, sub-ms, works offline.

2 Architecture Components

◆ TPA — Traceable Platform Agent

  • Deployment in harnessbank-demo-end2end
  • Chart: traceable-agent v1.71.2
  • Ports: gRPC :5441, HTTP/Zipkin :5442
  • MutatingWebhook for TME sidecar injection
  • Polls policies from platform every 30s
  • Auth: TA_REFRESH_TOKEN from token-secret

◆ TME — Traceable Module Extension

  • Sidecar injected into Nginx Ingress pod
  • ext_cap :5442 — inline request evaluation
  • collector :9411 — Zipkin span receiver
  • Blocking: WAF/CRS + ModSecurity + Custom Sigs
  • Sub-millisecond allow/block decision
  • Forwards spans to TPA in app namespace

◆ eBPF Tracer

  • DaemonSet, v1.31.0, 7 pods
  • Kernel-level passive capture
  • E-W traffic: App ↔ MCP Financial Data
  • Mode: ingress_and_egress
  • No blocking — discovery + telemetry only
  • Tolerations: ai_agentic_demo_space

◆ AST Runner

  • Deployment, traceable-runner v2.7.0
  • Active API Security Testing (DAST)
  • Scans discovered API endpoints
  • 20 concurrent threads
  • Server: api.us9.traceable.ai
  • NodeSelector: ai-agentic-demo

◆ Nginx Ingress Controller

  • Namespace: nginx (label: traceableai-inject-tme=enabled)
  • Pod: 2/2 containers + 1 init
  • Init: traceable-nginx-init copies Lua plugin
  • Container 1: controller (v1.10.1) with Lua plugin
  • Container 2: TME sidecar (v1.71.2)
  • Domain: demobank-e2e.selatam.harness-demo.site

◆ MCP Financial Data Service

  • ClusterIP :5001 in harnessbank-demo-end2end
  • /api/enrich — context enrichment for AI chat
  • /mcp/risk-profile — account risk data
  • Returns CONFIDENTIAL financial data
  • E-W traffic captured by eBPF tracer
  • Protected by AI Firewall MCP policies

Inline (TME) — Zero Latency

CRS, ModSecurity, IP lists, rate limiters run inside the TME sidecar. Deterministic, before the request leaves ingress. Works offline.

Platform (Async) — ML-Based

BOLA and AI Firewall use behavioral ML models on the platform. Spans sent async — zero request latency. Currently Monitor mode.

🛡 Input Protection

  • Prompt Injection — Jailbreak, role-override, instruction-override
  • Prompt Evasion — Base64, ROT13, Unicode bypass
  • Code in Prompt — Executable code in messages
  • AI Input Explosion — Oversized inputs to exhaust tokens

🔍 Data Protection

  • AI Sensitive Data — PII detection (SSN, credit cards)
  • PII in Tool Response — Financial data leaking from MCP
  • Exploit in LLM Output — Malicious payloads in responses
  • AI Rate Limiting — Throttle abusive AI usage

🔌 MCP Protection

  • MCP Schema Validation — Tool calls match expected schema
  • MCP Unauth Access — Block unauthorized invocations
  • Tool Response Explosion — Oversized MCP responses
  • Protects mcp-financial-data:5001

⚙ Governance

  • Model Governance — Approved models and providers
  • Agent Access Control — Restrict tool access per agent
  • Toxic Content — Hate speech, harassment detection
  • All configurable in Traceable Platform UI
